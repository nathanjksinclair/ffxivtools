# Welcome

Dear Reader,

Welcome to the wide-world of FFXIV plugin development. 

To get started you'll want to go on Dalamud's [GitHub](https://github.com/goatcorp/Dalamud) repository, and then head over to the [documentation](https://dalamud.dev/plugin-development/project-layout)

However the state of things you'll also want to clone the [InventoryTools](https://github.com/Critical-Impact/InventoryTools) repo which keep as it's dependancies [OtterGui](https://github.com/Ottermandias/OtterGui) and [AllaganLib](https://github.com/Critical-Impact/AllaganLib)

Development for FFXIV plugins takes place in C# and C++. For example C++ go look at [Dear IMGui](https://github.com/ocornut/imgui) which OtterGui depends on.

Obviously pointing at the documentation it will suggest setting up a template that uses [SamplePlugin](https://github.com/goatcorp/SamplePlugin) but I didn't really get anything from that.

Generally speaking, Dalamud is the plugin loader so if you're developing plugins, it has to meet Dalamud's requirements for it to work with FFXIV.
But whatever you want to develop, put in a repository and start coding!
